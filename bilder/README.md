# Bilder

Legg bilder og eksempler i denne mappen.

Foreslåtte filnavn:
- `logo.png` – Green Konsulenttjenester-logo
- `tegning-1.jpg` – eksempel på plantegning/byggetegning
- `detalj-1.jpg` – eksempel på detaljtegning
- `rapport-1.jpg` – eksempel/utdrag fra rapport
- `nettside-1.jpg` – skjermbilde av nettsideprosjekt
- `nettside-2.jpg` – skjermbilde av nettsideprosjekt

Når filene er lagt inn kan plassholderne i `index.html` byttes ut med de faktiske bildene.
